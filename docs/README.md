# DoodleWhirl! — Documentation

> Picking up the work? Start with [planning/status.md](planning/status.md).

DoodleWhirl! is a browser-based, real-time drawing-and-guessing game (in the spirit of Pictionary) built around **themed card decks**. The decks are generated by AI and shared by the community. Hosts pick a theme ("Halloween", "80s movies", "Kitchen"), choose one or more difficulty levels, and can turn on **Silly Mode** for absurd prompts like *"Vampire on a unicycle"* or *"Realtor Skeleton"*.

## The idea in one paragraph

Anyone (a registered user or a guest) can open the site, pick a display name and avatar, then join a public room from the lobby list or enter a private room code (`ABC-DEF`). Anyone can host a room. The host searches the deck library, picks a themed deck, chooses difficulty levels, optionally enables Silly Mode, and decides whether players can see each other's guesses. Players take turns drawing on a rich canvas while the others type guesses. Guesses that are *nearly* correct are redacted and shown in red so they don't give the answer away. Registered users can generate new decks with AI: a few generations are free, and after that they buy credits.
